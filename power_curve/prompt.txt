The history of large language model inference optimization is a history of trading compute for memory bandwidth and of hiding latency behind speculation. Early systems treated the GPU as a single monolithic compute engine and measured success in floating point operations per second, but modern decode workloads are largely memory bound: each generated token requires moving the entire weight matrix and the accumulated key value cache across the memory interface, so the useful arithmetic per byte transferred is extremely low. Quantization reduces the byte count by representing weights with fewer bits, and grouped quantization further reduces the number of scales that must be stored and read. Flash attention avoids materializing the full attention matrix in memory, and paged attention manages the key value cache in fixed size blocks so that concurrent sequences do not fragment the cache. Speculative decoding adds a draft mechanism that proposes several candidate tokens and then verifies them in a single forward pass, so the cost of the small draft is amortized over several accepted target tokens. The acceptance rate depends on how closely the draft model tracks the target model, and multi token prediction heads attached to the target model itself can produce drafts without a separate network. Power limiting caps the total energy the GPU may draw, and the driver responds by lowering the clock frequency until the workload fits under the cap, so a memory bound decode will slow down roughly in proportion to the available clock until it is no longer power limited.
